# 魚と海のトーン＆マナー

2026-09-06に指定された [アジの参照画像](aji-reference.png) を、今後追加する魚にも共通する表現の基準にします。
魚と海の背景はThree.jsの立体で表現し、水槽画面は既存のシンプルなUIを維持します。

## 表現

- 写実とキャラクターの中間。全身のシルエットから魚種が分かり、顔は親しみやすくする。
- 体は丸く滑らかにし、腹と肩に量感を持たせる。尾の付け根は細くつなぐ。
- 目は顔に対して大きくしすぎない。濃い輪郭・淡いクリーム色の虹彩・黒い瞳・小さな白いハイライトで構成する。アジは参照画像から起こした初版モデルの85%の大きさを基準にする。眼球を重ねた出っ張りは作らず、顔の曲面に沿う薄い面で目を描く。
- 表面は銀色のサテンに透明なツヤを重ねる。鏡面の金属や細かなノイズに寄せすぎない。
- 背中、側面、腹の色面を読み取りやすく分ける。うろこは控えめな面の変化で表す。
- ひれは薄く、先端を丸め、緩い湾曲と細い筋を付ける。単純な三角形にしない。
- 背びれ・下びれは滑らかな輪郭を優先する。第一背びれは高め、第二背びれは低く長めにし、背中の形状に付け根を沿わせる。ギザギザや折り返し、筋の交差、付け根の隙間を避ける。尻びれと左右の腹びれも同じ生成方法で腹の曲面につなぐ。
- えら、口、側線、ぜいごなどの特徴は残し、細線の描き込みでうるさくしない。
- 口は通常時に顔へなじませる。餌を食べるときだけ口角を支点に下顎を開き、唇と口内も一緒に動かす。開閉中に唇が浮いたり、顔との接続が割れたりしないようにする。
- 左右、正面、上面から見られる立体として作り、絵を貼った板で代用しない。

## アジの配色

| 部位 | 基準 |
| --- | --- |
| 背 | 深い青灰色 |
| 側面 | 明るい青灰色から銀色 |
| 腹 | 真珠のような白銀色 |
| ひれ・尾 | 淡い金色。根元と筋を濃く、先端を明るくする |
| 目 | クリーム色の縁、紺黒の瞳 |

魚の照明は一定の白色環境光に固定します。方向別の照明、環境の映り込みは使用しません。体の色面とモデル上のハイライトで形を表現し、素材の数値だけでなく水槽内で参照画像の印象に合うか確認します。海の背景に描いた光線は、魚の照明には影響させません。

## 実装

- `src/fish/visualStyle.ts` に共通の質感とアジの基準色を定義。
- `src/fish/species.ts` には魚種ごとの配色、体型、泳ぎ方を定義。
- `src/fish/createFish.ts` で体と顔、湾曲したひれ、可動下顎と口内を生成。口の位置を給餌処理へ渡し、群れの複製も個体ごとの下顎の変形で開閉する。
- `src/feeding.ts` でオキアミの表現、落下、魚ごとの追跡と開口、飲み込み、元の遊泳への復帰を管理する。
- `src/oceanEnvironment.ts` で海底・岩・海藻・サンゴ・水中の光と水深別の表現を生成し、`src/shelterMotion.ts` で継続的な遊泳と岩陰への立ち寄り、餌による呼び戻しの位置・向き・大きさを管理する。
- ほかの魚種では固有の色・模様・体型を保ち、顔に収まる目、滑らかな面、控えめなツヤという表現を共有する。
- アジの黄色いひれや形状をすべての魚に流用しない。

## 調整する場所

- 目の比率：`visualStyle.ts` の `proportions.eyeScale`。現在は `0.85`。縁、虹彩、瞳、ハイライトの寸法と位置をまとめて縮小する。
- 背びれ：`createFish.ts` の `bodyFin()`。第一背びれの高さは `0.44`、第二背びれは `0.34`（モデル座標）。
- 背びれの輪郭は連続した高さの関数で定義し、根元は胴体の断面形状に追従させる。
- ひれの面と筋は `finSurface()` で共通生成。背びれの筋は半径 `0.0025` で控えめにする。
- 胸びれと尾びれは `ribbonFin()` を使用する。
- 第一背びれは頂点を後方へ寄せ、筋にも後方への傾きを付ける。
- ひれの金色のグラデーションと筋の陰影は頂点色で描く。照明の変更に頼らない。
- 背中と側面の銀色の反射は `skinTexture()` に左右対称で描き、独立した帯状メッシュは使わない。

- 目は `eyePatch()` で顔の表面に追従させ、縁から瞳までの奥行きの差を最小限にする。
- `bodyFin()` の角度で背びれ・尻びれ・左右の腹びれを描き分ける。

## 確認

1. 横から、シルエット・顔・背中と腹の色・ひれの輪郭を確認。
2. 回転して、両側の目・えら・胸びれが体につながっているか確認。
3. 遊泳中に尾とひれの境界が割れて見えないか確認。
4. 群れ表示とスマートフォン幅で、縮小しても魚種と表情が読み取れるか確認。
5. アジ・イワシ・カサゴの餌やりで、口の開閉が顔になじみ、オキアミが口へ入る動きが読み取れるか確認。群れでもそれぞれの魚が個別に口を動かすことを確認。

## イワシ

参照画像： [イワシ](../魚_イメージ図/イワシ.png)。黒い斑点を持つイワシとして表現します。

- アジと同じ白銀色の質感と、顔に沿う目・口を共有する。
- 体はアジより細長くし、目の縦横比は補正して丸く保つ。
- 背びれは中央に1枚。尻びれは後方、腹びれは腹の中央寄りに置く。
- 体の両側に9つの黒い斑点を表面に沿って描く。アジのぜいごは付けない。
- ひれは淡い灰金色。ひれの筋と先端の色も魚種別の配色にする。
- 選択時には本体と群れをまとめて入れ替え、古い共有素材・形状を破棄する。

## カサゴ

ローカルの参照画像：`魚_イメージ図/カサゴ.png`。画像は公開ファイルに含めず、専用の `rockfish` モデルを生成します。

- 大きな頭と厚みのある胴、短く太い尾の付け根を、丸みのある面でつなぐ。
- 赤茶色・焦げ茶・クリーム色の不規則な模様を胴体の全周へ描き、腹は柔らかいベージュにする。銀色の反射は使わない。
- 背びれは膜でつながるトゲの列と丸い後部、尾びれは二股にしない扇形。胸びれは左右へ広がる大きな扇にして、筋と淡い縁を付ける。
- 顔の小さなトゲ、金色の虹彩、薄い茶色のえらの縁を付ける。目は既存モデルと同様、顔の表面へなじませる。
- カサゴの口角は目の下で終える。唇は赤茶色の薄い面で顔に沿わせ、短い下顎を控えめに開く。口内はアジ・イワシと同じ上面・下面で表現し、口の開口部を黒い側面の膜で覆わない。下顎と胴体の接続には体色の伸縮する面を残し、顎下の隙間を防ぐ。群れの複製も個体ごとに開閉する。
- 生物情報（メバル科・学名・大きさ）は[新潟市水族館 マリンピア日本海](https://www.marinepia.or.jp/picturebook/fish/entry-11171.html)と[加茂水族館](https://kamo-kurage.jp/shonaizukan/kasago/)を参考にする。模様や立体表現の基準は添付画像を優先する。

## 図鑑と海の深さ

- 図鑑は濃紺の直角のパネルに、実際の3Dモデルを標本のように並べる。細い罫線と余白、明朝体の見出しで構成し、選択中の魚は淡い緑の下線と小さな表示で区別する。
- サムネイルは図鑑を初めて開いたときに順番に生成して保持する。魚と同じ固定の環境光で撮影し、撮影用のモデル・レンダラーを破棄する。
- 水深は [参照画像](../魚_イメージ図/水深.png) に合わせて50m・100m・150mの3段階にする。50mは明るい水色、差し込む光と砂地。100mは深い青と岩場。150mは光の弱い濃紺の海として描く。
- 海底の起伏、面のある岩、海藻、枝状のサンゴをコードから生成し、魚と同じ3D空間に配置する。中央には観察と餌やりの余白を保ち、手前の岩は魚が隠れられる厚みを持たせる。従来の `public/backgrounds/` のPNG画像は参考として残し、画面の描画には読み込まない。
- 水中の光線と海底に揺らぐ光模様を描き、50mでは明るく、100mでは控えめに、150mでは弱くする。水深変更は同じ立体の海に色・霧・光の変化を与え、魚の照明は一定の白色環境光に保つ。光量を調整する操作は設けない。
- 遠景は水深に合う霧で奥行きを付ける。50mでは魚の説明・図鑑・操作アイコンに濃紺の文字と明るい半透明の背景を使い、岩場や明るい水面の上でも読みやすくする。
- 操作は小さな「水深」のラベルと現在値、`input type="range"` のみ。50m・100m・150mの3段階にし、細いトラックと四角いノブで表す。画像内の説明文や英語のコピーは画面に追加しない。
- 水深は観賞用の設定で、魚の生息可能な深度を制限するものではない。

## 遊泳と岩陰への立ち寄り

- 岩陰の位置は岩の内部に置かず、実際の形状より奥に空間を確保する。魚は中央の通路から奥へ進み、全身が岩の裏へ抜けてから横へ曲がる。餌による呼び戻しでもこの通路を使い、体とひれが岩を横切らないようにする。

- 初回表示と魚種変更時は魚を岩の外に見せる。緩やかな上下移動と奥行きを含む曲線に沿って泳ぎ続け、進む方向へ滑らかに頭を向ける。急な折り返しや、移動方向と合わない横滑りを避ける。
- ときどき岩陰へ立ち寄り、短時間休んだ後は自分から出て遊泳を再開する。一定時間で隠れたままにせず、操作しなくても観察を楽しめる流れにする。
- 群れは5匹すべてを同程度の大きさにし、岩の手前の広い水中を回遊させる。固定された四隅の小さな揺れに留めず、それぞれが画面内を移動する。個体ごとに速さ・曲がるタイミングを変え、頭を進行方向に向けて滑らかに泳がせる。体が重なる一点への集合は避ける。1匹表示では岩陰への立ち寄りを継続する。
- エビアイコンで岩の外へ餌を落とし、遊泳中・岩陰・岩へ向かう途中の魚を呼び戻す。現在の位置と向きから餌のある場所へ滑らかにつなぎ、岩の外で追跡を始める。餌が残っている間は岩の外に留め、食べ終えたら遊泳を続ける。新しい説明文や操作ボタンは増やさない。
- カメラの回転範囲は海底の下へ潜らないように制限する。スマホでも岩陰と観察位置が画面に収まる配置にする。
- OSのモーション軽減設定では魚を岩の外に表示し、通常の遊泳と出入りを止める。明示的に始めた餌やりは動作する。

## UIの形状（2026-09-07）

- 水深パネル・図鑑・魚のカード・閉じるボタン・選択表示は角丸を使わない。周囲のメニュー、操作アイコンの背景、魚の説明にも同じ直角の形状を使う。
- 水深は現在値と細いスライダーへ整理し、図鑑の選択中の魚は淡い緑の下線で示す。
- 濃紺、淡い銀色の罫線、控えめな緑のアクセントを共有する。余分な囲みや強い影は避ける。

## オキアミと餌やり（2026-09-07）

- 群れ切り替えの直下にエビの線画アイコンを置く。新しい説明パネルは増やさず、ツールチップと読み上げ用の名前で操作を伝える。
- オキアミは魚と同じ立体表現で、淡いサンゴ色の節、尾、目、触角を持つ小さな形にする。魚より目立ちすぎず、3段階の背景の中で追える色と大きさを保つ。
- クリックで岩の外にオキアミを投入し、ゆっくり沈ませる。魚が岩陰にいる場合も餌は外から見える位置へ置く。遊泳中や岩陰から滑らかに呼び戻し、岩の外に魚ごとの餌を分散して置き、それぞれ自分の餌を追う。同じ場所へ全員が集まる演出にはしない。口へ近づくにつれて顎を開き、飲み込んだ後に閉じて遊泳へ戻る。アジ・イワシ・カサゴ、1匹・群れで同じ流れにする。
- 連続クリックによる投入は同時24粒まで。食べ残しは18秒で消し、魚種変更では餌と追跡状態をリセットする。
- OSのモーション軽減設定では岩の外で通常の遊泳・出入りを止めるが、利用者が明示的に始めた餌やりは実行する。

## 読み込みとスマートフォン操作

- 初期HTMLに濃紺のローディングと魚の線画を配置し、外部スクリプトやフォントを待たずに表示する。水槽の初回描画が済んでから切り替える。
- 待機中は背後の操作を無効にし、読込失敗や長時間待機時には再読み込みを案内する。モーション軽減設定ではローディングの動きを止める。
- スマホのピンチ・ダブルタップによる拡大を抑止する。魚の大きさは＋／−ボタンで変更し、1本指の回転や図鑑の縦スクロールは保つ。
- 餌やりは開いた口の中央を追従し、オキアミが唇を越えて口内へ入ってから縮小する。飲み込む間は魚の傾きを安定させる。
