# SAKANA — 小さな海を、ブラウザのなかに。

Three.jsで作った海底と岩場で、アジ・イワシ・カサゴがゆったり泳ぐ様子を観察し、オキアミをあげられるブラウザ用プロトタイプです。
現在の魚は3種類。将来的に約50種類へ増やすため、魚の定義・モデル生成・水槽の表示を分けています。

公開URL: **https://miyamoto-shinji.github.io/experiment/02_sakana/**

## 起動

Node.js 22.12以降を使用してください。
このフォルダで以下を実行します。

```sh
npm install
npm run dev
```

ブラウザで http://127.0.0.1:5174/ を開きます。停止は起動したターミナルで Ctrl+C。
HTMLファイルを直接開くのではなく、上記の開発サーバーを使ってください。

```sh
npm run build    # 型チェックと公開用ファイル生成（dist/）
npm test         # 3Dの海・岩陰の出入り・全魚種の形状と餌やりを確認
npm run preview  # 公開用ファイルを http://127.0.0.1:4174/ で確認
```

この水槽は `02_sakana/dist/` を公開用フォルダの `02_sakana/` へ配置します。ひらがなアプリは別の `01_hiragana/` に配置し、魚モデルの参照画像・ソース・ドキュメントは公開用ファイルに含めません。`dist/` や `_site/` をGitに追加する必要はありません。新しいアプリの追加方法は[リポジトリのREADME](../README.md)を参照してください。

リポジトリの **Settings → Pages → Source** は **GitHub Actions** を使用します。公開先のサブパスでもJavaScript・CSSが読み込めるよう、Viteの `base` を相対パスにしています。

## できること

- アジ：銀色の体、2つの背びれ、金色のひれ、ぜいごを立体表示
- イワシ：細長い銀色の体、1つの背びれ、淡い灰金色のひれ、両側に9つの黒い斑点を立体表示
- カサゴ：大きな頭、赤褐色とクリーム色のまだら模様、連続したトゲの背びれ、扇形の胸びれと尾びれを専用モデルで立体表示
- 体から尾へ伝わる泳ぎのアニメーション
- ドラッグで回転、パソコンのスクロール・画面のボタンで拡大縮小、視点リセット。回転は海底の下へ潜らない範囲に制限
- 手前と奥を行き来する立体的な回遊。魚は進行方向へ頭を向け、カーブで体を少し傾け、緩やかに上昇・下降する。1匹表示ではときどき岩陰へ立ち寄って自分から出てくる
- 魚の照明は一定の明るさ。方向別の照明・環境の映り込みは使用しません
- 全画面アイコンの下の魚アイコンで、1匹／5匹の群れを切り替え
- 群れアイコンの下のエビアイコンで岩の外へオキアミを投入。隠れている魚も岩陰から出て、3種類とも個別に追いかけ、口を開けて食べる
- 3Dモデルのプレビュー付き図鑑、対応ブラウザでの全画面表示
- 海底・岩・海藻・サンゴ・水中の光をThree.jsで立体描画。50m・100m・150mのスライダーで海の色・霧・海底に揺らぐ光を変え、水深をブラウザに保存
- 砂地にはうねり、低い水路、広いくぼみ、小さな穴を立体的に生成。砂の細かな筋と粒、大小の砂利、石の接地影で海底の質感を表現
- 岩陰から小さなイワシ3匹が出入りし、ときどき遠景を大きな魚影が横切る。大きな魚影の通過に合わせてイワシが隠れ、落ち着くと再び出てくる
- スマートフォンのピンチ・ダブルタップによる画面拡大を抑止。1本指の回転、図鑑のスクロール、水深スライダー、＋／−ボタンは利用可能
- 初期HTMLから読み込み表示を出し、水槽の初回描画後に切り替え。読み込み失敗や長時間待機時は再読み込みを案内
- スマートフォン対応。OSの「視差効果を減らす」等の設定では岩の外で魚を表示して通常の遊泳・出入りを止め、クリックで始めた餌やりの動きは実行

この段階では観察・餌やりを楽しむデモです。捕獲、スコア、ゲーム進行のセーブ機能、ほかの魚はまだ実装していません。
魚は特徴を強調した表現で、学術用途の精密モデルではありません。

## 現在の画面・操作

- ヘッダーは「図鑑」のメニューのみ。モーダル内は魚のプレビュー、名前、科・全長を載せたカードです。選択中の魚を表示し、カード選択、閉じるボタン、背景クリック、Escキーで閉じられます。スマートフォンでは縦に並びます。図鑑と水深パネルは角丸を使わず、細い罫線で統一しています。図鑑の選択中の魚は下線で示します。
- 右側には視点リセット、拡大、縮小、全画面、群れの切り替え、その直下にエビの餌やりアイコンを並べています。
- 群れアイコンはクリックで1匹／5匹を切り替え、アイコン・色・ツールチップ・読み上げ用の名前を更新します。
- カサゴの口は短い下顎と顔に沿う薄い唇で構成し、口内の面が顎と一緒に動きます。餌は開いた口の中央を追従し、口内へ入ってから小さく消えます。
- 最初の表示と魚種変更時は魚を岩の外に表示し、緩やかな上下移動と奥行きのある曲線に沿って泳ぎ始めます。進む方向へ自然に向きを変え、ときどき岩陰へ立ち寄ります。岩陰に留まるのは短時間で、その後は自分から出て遊泳を続けます。魚と岩を同じ3D空間に置いているため、隠れ方は視点によって変わります。出入りは中央の通路から岩の裏へ回り込み、魚の体やひれが岩を通り抜けない経路を使います。群れ表示では5匹すべてを同程度の大きさにし、岩より手前の広い水中を泳がせます。個体ごとに速さや曲がるタイミング、上下の揺れを変え、手前と奥へ大きく回遊します。進行方向へ頭を向け、旋回に合わせて体を少し傾けます。経路の長さを考慮して速度を調整し、カーブでも滑らかに進みます。固定された四隅での待機や、一点への集合は行いません。1匹表示では従来の岩陰への立ち寄りを行います。
- エビアイコンを押すと小さなオキアミが岩の外に落ち、遊泳中・岩陰・岩へ向かう途中の魚が、現在の位置と向きから滑らかに餌のある場所へ戻ります。オキアミを魚ごとの位置へ分散して投入し、それぞれ自分の餌を追います。下顎を動かして口を開け、飲み込んだ後に広い範囲の遊泳へ戻ります。餌が残っている間は岩の外に留まります。1匹・群れ、アジ・イワシ・カサゴに対応します。
- オキアミは同時に24粒まで投入でき、上限に達するとエビアイコンが一時的に無効になります。食べ残しは18秒で消え、魚種を切り替えるとオキアミと追跡状態をリセットします。
- 左下の番号・名前・漢字・説明・科・全長は、選択した魚に合わせて更新します。
- 遠ざかる魚が小さく、近づく魚が大きく見える遠近法で奥行きを表現します。通常の遊泳では魚自体の大きさを一定に保ちます。岩の狭い通路への出入りには既存の大きさの調整を使います。横に広い画面でも群れが収まるよう視点を調整します。
- 魚は自動で泳ぎます。速度設定と停止ボタンはありません。OSのモーション軽減設定では岩の外で通常の遊泳・出入りを止めますが、利用者がクリックした餌やりは動作します。
- 画面上部の紹介文、魚の横のラベル、学名、「海水魚」、`MEET YOUR FISH`、操作の案内文、フッター、図鑑の追加予定案内は削除済みです。
- 右下（スマートフォンでは下部）の `input type="range"` で、50m・100m・150mの海へ切り替えます。小さな「水深」と現在値、細いトラックと四角いノブのみの構成です。ドラッグ・タップ・矢印キーで操作できます。50mは明るい水色と砂地、100mは青い岩場、150mは濃紺の暗い海です。立体の海底や岩を保ったまま、海の色・霧・水中の光を変えます。
- 初期値は50mで、設定を次回も復元します。過去の保存値は最も近い水深へ移行し、空欄や不正な値は50mに戻します。魚種を変えても水深は維持します。
- 水深は観賞用の背景設定です。水面から差し込む光や海底の光模様は海の演出として描き、魚の照明は一定の白色環境光に保ちます。光量調整の機能は追加していません。
- 背景には岩場の小魚と遠景の大きな魚影を配置します。主役の1匹／5匹とは別の環境演出で、岩による遮蔽と水中の霧を使って奥行きを見せます。背景の時間は魚種を切り替えても継続し、OSのモーション軽減設定では進行を止めます。モデルは軽量な形状・素材を共有し、追加画像の読み込みはありません。

## 表現の基準

魚のトーン＆マナーは [添付のアジ画像](魚_イメージ図/アジ.png) を基準にしています。顔とのバランスを整えた目、丸みのある銀色の体、青灰色の背中、淡い湾曲したひれをThree.jsの立体モデルで表現しています。目は参照画像から起こした初版モデルの85%に縮小し、瞳をやや小さくしてクリーム色の虹彩を見せています。目は顔の表面に沿う薄い面で描き、突出を抑えています。背びれ・尻びれ・腹びれは体に沿う付け根、滑らかな輪郭、細い筋で構成しています。体の反射はテクスチャ、ひれの淡い金色と筋の陰影は頂点色で表現しています。イワシは [参照画像](魚_イメージ図/イワシ.png) に合わせ、1枚の背びれと黒い斑点を持つ細長い体にしています。今後の魚を追加する際は [ART_DIRECTION.md](docs/ART_DIRECTION.md) を参照してください。

## 魚を追加する方針

1. `src/sakana/` に魚ごとのファイルを作り、固有のID・表示名・番号・説明・配色・体型・泳ぎの係数と、`FishInstance` を返す生成関数を定義します。アジは `aji.ts`、イワシは `iwashi.ts`、カサゴは `kasago.ts` を編集します。
2. アジ・イワシに近い体型は `createStreamlinedFish()` を再利用し、専用ファイルからひれの配置や模様を描く処理を渡します。共通の体・目・口や、ひれを細かい面に分割する処理を魚ごとにコピーしないようにします。
3. カサゴのように大きく異なる体型は専用ファイルで組み立て、必要に応じて体形・口・模様を補助ファイルへ分けます。共通の泳ぎの変形と口の開閉の制御は再利用します。新しい体型の分類が必要な場合は `FishSpecies.body` の型にも追加します。この分類で生成関数を分岐させる必要はありません。
4. `registry.ts` に魚の情報と生成関数を一組で登録します。図鑑の選択肢・件数・並び順と、`createFish()` の呼び出し先はこの登録から決まるため、図鑑や水槽に魚種ごとの分岐を追加する必要はありません。
5. 新しいモデルも口の位置・開閉、時間に応じた更新、`dispose()` を実装します。魚の切り替え時は既存の `aquariumFish.ts` が餌やりと岩陰の出入りをリセットし、群れ表示の状態を維持します。複製は形状・素材を共有するため、元モデルと複製をシーンから外した後に共有リソースを破棄します。

同じ素材のパーツを結合し、群れでは形状・素材を共有しています。「50種類を選べること」と「50種類を同時に表示すること」は負荷が異なるため、多種類の同時表示を追加する段階で、距離に応じたモデルの簡略化や同時表示数を調整してください。

## 確認手順

1. `npm run build` で型チェックと公開用ビルドを確認します。
2. ブラウザでアジが最初から岩の外に見え、上下・奥行きのある曲線に沿って泳ぎ続けることを確認します。進行方向へ自然に向きを変え、岩陰へ立ち寄った後は、操作しなくても短時間で再び出てくることを確認します。
3. 回転・拡大して、目の大きさ、背びれの輪郭、付け根のつながりを確認します。岩と魚の前後関係が視点に応じて変わり、カメラが海底の下へ潜らないことも確認します。
4. 群れアイコンで1匹→5匹→1匹へ切り替えます。5匹すべてが広い範囲を泳ぎ、進行方向に頭を向けて滑らかに曲がることを確認します。時間が経っても固定位置に留まらず、餌やり後にも回遊へ戻り、一箇所に集まらないことを確認します。
5. 図鑑でアジ→イワシ→カサゴ→アジと切り替え、名前・説明・模様・ひれが連動することを確認します。群れ表示中にも切り替えます。
6. 水深スライダーをドラッグ・矢印キーで50m・100m・150mへ変更し、立体の海底・岩の色、霧、光模様と現在値が連動すること、魚を変更しても水深が維持されること、再読み込み後に復元されることを確認します。50mで魚の説明・図鑑・操作アイコンが明るい背景上でも読めることを確認します。
7. 3種類それぞれの1匹表示と群れ表示で、遊泳中・岩陰・岩へ向かう途中にエビアイコンを押します。魚が現在の位置と向きから滑らかに餌のある場所へ戻り、岩の外で追跡・開口・飲み込みを始めること、餌が残る間は岩へ向かわないことを確認します。回転しても顎が顔から離れないことを確認します。`npm test` では海の形状・3段階の色・リソース破棄、長時間の遊泳と岩陰からの再出現、遊泳・出入り中の呼び戻し・モーション軽減、形状の数値・支点固定・クローンの独立、3種類とスマートフォンでの餌やり、寿命前の完食、リセット・リソース破棄を確認します。
8. エビアイコンの連打で24粒の上限を超えないこと、食べ残しが18秒で消えること、魚種変更で残った餌と追跡状態が消えることを確認します。OSのモーション軽減設定中にも明示的な餌やりが動くことを確認します。
9. スマートフォン幅で図鑑が縦に並び、水深設定やエビアイコンが魚の説明に重ならないことを確認します。ピンチ・ダブルタップでページが拡大せず、1本指の回転・図鑑スクロール・スライダー・＋／−ボタンが動くことを確認します。
10. 低速接続でもローディングが先に表示され、水槽の初回描画が済んでから消えることを確認します。スクリプトの読み込み失敗時に再読み込み操作が表示されることも確認します。図鑑を閉じて開き直してもプレビューが再生成されないことを確認します。
