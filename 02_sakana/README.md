# SAKANA — 小さな海を、ブラウザのなかに。

Three.jsで作った、泳ぐアジ・イワシ・カサゴを観察し、オキアミをあげられるブラウザ用プロトタイプです。
現在の魚は3種類。将来的に約50種類へ増やすため、魚の定義・モデル生成・水槽の表示を分けています。

公開URL: **https://miyamoto-shinji.github.io/experiment/02_sakana/**

## 起動

Node.js 22.12以降を使用してください。
このフォルダで以下を実行します。

```sh
npm install
npm run dev
```

ブラウザで http://127.0.0.1:5174/ を開きます。停止は起動したターミナルで Ctrl+C。
HTMLファイルを直接開くのではなく、上記の開発サーバーを使ってください。

```sh
npm run build    # 型チェックと公開用ファイル生成（dist/）
npm test         # 全魚種の形状・口の独立した開閉・1匹/群れの餌やりを確認
npm run preview  # 公開用ファイルを http://127.0.0.1:4174/ で確認
```

## GitHub Pagesへの公開

`main` ブランチを更新すると、[共通の公開ワークフロー](../.github/workflows/deploy-pages.yml) が番号付きの各プロジェクトをビルドし、フォルダ名ごとのURLへ自動で公開します。GitHubのActions画面から手動実行することもできます。

この水槽は `02_sakana/dist/` を公開用フォルダの `02_sakana/` へ配置します。ひらがなアプリは別の `01_hiragana/` に配置し、参考画像・ソース・ドキュメントは公開用ファイルに含めません。`dist/` や `_site/` をGitに追加する必要はありません。新しいアプリの追加方法は[リポジトリのREADME](../README.md)を参照してください。

リポジトリの **Settings → Pages → Source** は **GitHub Actions** を使用します。公開先のサブパスでも画像が読み込めるよう、Viteの `base` を相対パスにし、背景画像にも同じ基準を使っています。

## できること

- アジ：銀色の体、2つの背びれ、金色のひれ、ぜいごを立体表示
- イワシ：細長い銀色の体、1つの背びれ、淡い灰金色のひれ、両側に9つの黒い斑点を立体表示
- カサゴ：大きな頭、赤褐色とクリーム色のまだら模様、連続したトゲの背びれ、扇形の胸びれと尾びれを専用モデルで立体表示
- 体から尾へ伝わる泳ぎのアニメーション
- ドラッグで回転、スクロール・ピンチ・ボタンで拡大縮小、視点リセット
- 一定の速さで自動遊泳
- 魚の照明は一定の明るさ。方向別の照明・環境の映り込みは使用しません
- 全画面アイコンの下の魚アイコンで、1匹／7匹の群れを切り替え
- 群れアイコンの下のエビアイコンでオキアミを投入。3種類とも個別に追いかけ、口を開けて食べ、元の遊泳に戻る
- 3Dモデルのプレビュー付き図鑑、対応ブラウザでの全画面表示
- 水深を50m・100m・150mのスライダーで選択。参照画像に合わせた海中イラストへ背景を切り替え、水深をブラウザに保存
- スマートフォン対応。OSの「視差効果を減らす」等の設定では通常の遊泳を止め、クリックで始めた餌やりの動きは実行

この段階では観察・餌やりを楽しむデモです。捕獲、スコア、ゲーム進行のセーブ機能、ほかの魚はまだ実装していません。
魚は特徴を強調した表現で、学術用途の精密モデルではありません。

## 現在の画面・操作

- ヘッダーは「図鑑」のメニューのみ。モーダル内は魚のプレビュー、名前、科・全長を載せたカードです。選択中の魚を表示し、カード選択、閉じるボタン、背景クリック、Escキーで閉じられます。スマートフォンでは縦に並びます。図鑑と水深パネルは角丸を使わず、細い罫線で統一しています。図鑑の選択中の魚は下線で示します。
- 右側には視点リセット、拡大、縮小、全画面、群れの切り替え、その直下にエビの餌やりアイコンを並べています。
- 群れアイコンはクリックで1匹／7匹を切り替え、アイコン・色・ツールチップ・読み上げ用の名前を更新します。
- エビアイコンを押すと小さなオキアミが水中に落ちます。魚はそれぞれ別のオキアミを追い、下顎を動かして口を開け、飲み込んだ後に元の位置と遊泳へ戻ります。1匹・群れ、アジ・イワシ・カサゴに対応します。
- オキアミは同時に24粒まで投入でき、上限に達するとエビアイコンが一時的に無効になります。食べ残しは18秒で消え、魚種を切り替えるとオキアミと追跡状態をリセットします。
- 左下の番号・名前・漢字・説明・科・全長は、選択した魚に合わせて更新します。
- 魚は自動で泳ぎます。速度設定と停止ボタンはありません。OSのモーション軽減設定では通常の遊泳を止めますが、利用者がクリックした餌やりは動作します。
- 画面上部の紹介文、魚の横のラベル、学名、「海水魚」、`MEET YOUR FISH`、操作の案内文、フッター、図鑑の追加予定案内は削除済みです。
- 右下（スマートフォンでは下部）の `input type="range"` で、50m・100m・150mの海へ切り替えます。小さな「水深」と現在値、細いトラックと四角いノブのみの構成です。ドラッグ・タップ・矢印キーで操作できます。50mは明るい水色と砂地、100mは青い岩場、150mは濃紺の暗い海です。背景は約0.45秒で切り替わります。
- 初期値は50mで、設定を次回も復元します。過去の保存値は最も近い水深へ移行し、空欄や不正な値は50mに戻します。魚種を変えても水深は維持します。
- 水深は観賞用の背景設定です。背景に水面や差し込む光を描き、魚の照明は一定の白色環境光に保ちます。光量調整の機能は追加していません。

## 表現の基準

魚のトーン＆マナーは [添付のアジ画像](docs/aji-reference.png) を基準にしています。顔とのバランスを整えた目、丸みのある銀色の体、青灰色の背中、淡い湾曲したひれをThree.jsの立体モデルで表現しています。目は参照画像から起こした初版モデルの85%に縮小し、瞳をやや小さくしてクリーム色の虹彩を見せています。目は顔の表面に沿う薄い面で描き、突出を抑えています。背びれ・尻びれ・腹びれは体に沿う付け根、滑らかな輪郭、細い筋で構成しています。体の反射はテクスチャ、ひれの淡い金色と筋の陰影は頂点色で表現しています。イワシは [参照画像](魚_イメージ図/イワシ.png) に合わせ、1枚の背びれと黒い斑点を持つ細長い体にしています。今後の魚を追加する際は [ART_DIRECTION.md](docs/ART_DIRECTION.md) を参照してください。

## ファイル

- `src/fish/visualStyle.ts`：共通の質感・配色・目の表現
- `src/fish/species.ts`：種のID、名前、配色、体型、泳ぎ方の定義
- `src/fish/createFish.ts`：立体モデル・うろこのテクスチャ生成、泳ぎの変形、口の位置と個体ごとに動く下顎
- `src/fish/createRockfish.ts`：カサゴの太い体型・まだら模様・トゲ・扇形のひれを生成する専用モデル
- `src/fish/fishModel.ts`：魚モデル共通のインターフェースと、魚種ごとの支点を使った口の開閉
- `src/feeding.ts`：オキアミの共有モデル、投入・落下・個体ごとの追跡・開口と飲み込み・遊泳への復帰、上限・寿命・リセットの管理
- `src/main.ts`：水槽、照明、カメラ、群れ、操作
- `src/collection.ts` / `src/collection.css`：図鑑カードと一度だけ生成する3Dモデルのサムネイル
- `src/oceanDepth.ts` / `src/oceanDepth.css`：3段階の水深スライダー、現在値、背景イラストの切り替え、霧・文字色の調整、設定の保存
- `public/backgrounds/ocean-50m.png` / `ocean-100m.png` / `ocean-150m.png`：水深ごとの海中背景。読み込めない場合は同系色のグラデーションを表示
- `src/icons.ts`：共通アイコンと、操作名・ツールチップの更新
- `src/style.css`：画面とスマートフォン用レイアウト
- `index.html`：日本語の説明と操作パネル

魚は外部の画像や3Dファイルを使わず、形状とテクスチャをコードから生成します。
フォントはGoogle Fontsを利用し、読み込めない場合は端末の標準フォントへ切り替わります。

## 魚を追加する方針

1. `species.ts` に種の定義と表示名・番号・説明を追加します。図鑑の選択肢と件数は定義から生成します。
2. アジと近い体型は既存の `carangid` モデルで配色・比率・尾びれサイズ・泳ぎ方を調整できます。
3. イワシは `clupeid` 分岐でひれの配置と斑点を描き分けます。カサゴは `rockfish` と専用の `createRockfish()` を使います。タイ、フグ、ウナギなど大きく異なる体型も、`FishSpecies.body` とモデル生成処理に専用の体型を追加します。色替えだけで全種類を表現する設計ではありません。
4. 選択時は餌やりの状態をリセットし、`createFish()` で新しい魚を作り、元の魚と群れを外してから共有素材・形状を破棄します。群れ表示の状態を維持します。新しい体型にも口の位置と開閉の処理を用意します。
5. 魚を入れ替える際はシーンから外し、その魚の `dispose()` を呼びます。群れの複製は形状・素材を共有するため、複製もシーンから外した後に元モデルを破棄します。

同じ素材のパーツを結合し、群れでは形状・素材を共有しています。「50種類を選べること」と「50種類を同時に表示すること」は負荷が異なるため、多種類の同時表示を追加する段階で、距離に応じたモデルの簡略化や同時表示数を調整してください。

## 確認手順

1. `npm run build` で型チェックと公開用ビルドを確認します。
2. ブラウザでアジが表示され、尾を振って泳ぐことを確認します。
3. 回転・拡大して、目の大きさ、背びれの輪郭、付け根のつながりを確認します。
4. 群れアイコンで1匹→7匹→1匹へ切り替えます。
5. 図鑑でアジ→イワシ→カサゴ→アジと切り替え、名前・説明・模様・ひれが連動することを確認します。群れ表示中にも切り替えます。
6. 水深スライダーをドラッグ・矢印キーで50m・100m・150mへ変更し、背景イラストと現在値が連動すること、魚を変更しても水深が維持されること、再読み込み後に復元されることを確認します。50mで魚の説明・図鑑・操作アイコンが明るい背景上でも読めることを確認します。
7. 3種類それぞれの1匹表示と群れ表示でエビアイコンを押し、オキアミの落下、個別の追跡、開口、飲み込み、通常の遊泳への復帰を確認します。回転しても顎が顔から離れないことを確認します。`npm test` では形状の数値・支点固定・クローンの独立・寿命前の完食・リセット・リソース破棄を確認します。
8. エビアイコンの連打で24粒の上限を超えないこと、食べ残しが18秒で消えること、魚種変更で残った餌と追跡状態が消えることを確認します。OSのモーション軽減設定中にも明示的な餌やりが動くことを確認します。
9. スマートフォン幅で図鑑が縦に並び、水深設定やエビアイコンが魚の説明に重ならないことを確認します。
