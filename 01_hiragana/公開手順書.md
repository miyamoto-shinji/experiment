# もじのもり 公開手順書

「もじのもり」は、くまのモクと一緒にひらがな46文字で遊ぶブラウザゲームです。
スマホ・タブレットではタップ、パソコンではマウスで遊べます。

## GitHub Pagesでの公開

公開URL：[もじのもり](https://miyamoto-shinji.github.io/experiment/01_hiragana/)

このリポジトリでは、`main` の更新をGitHub Actionsが自動でビルドし、`01_hiragana/dist/` の中身を上記URLへ公開します。アジの水槽など他のアプリも、それぞれのフォルダ名のURLへ同時に公開します。GitHub Pagesを利用する場合は、ZIPの作成や手動アップロードは必要ありません。

公開の進行状況はリポジトリの「Actions」で確認できます。公開が完了したら、下記「3. 公開後の確認」を行ってください。以下のZIP・レンタルサーバーの手順は、GitHub Pages以外へ設置する場合に使います。

## 1. アップロードするもの

納品ZIP `moji-no-mori-1.0.0.zip` を解凍してください。

- `moji-no-mori` フォルダ：公開するゲーム本体
- `README-ja.txt`：この手順書

ゲーム本体の中には、次のファイルが入っています。

```
moji-no-mori/
  index.html
  favicon.svg
  assets/
  licenses/
```

フォルダ構成を保ったまま、すべてアップロードします。
サーバーにNode.jsやデータベースを設置する必要はありません。
開発用の `src`、`node_modules`、`package.json` をアップロードする必要もありません。

## 2. レンタルサーバーに公開する

1. サーバーのファイルマネージャー、またはFTP/SFTPソフトを開きます。
2. 対象ドメインの公開フォルダを開きます。名称はサーバーによって `public_html`、`www`、`htdocs` などです。
3. 解凍した `moji-no-mori` フォルダを、そのまま公開フォルダへアップロードします。
4. ブラウザで `https://あなたのドメイン/moji-no-mori/` を開きます。

別のフォルダ名に変えても動作します。URLは末尾の `/` まで付けて開いてください。
ドメイン直下で公開する場合は、`moji-no-mori` の中身を公開フォルダ直下へ配置します。すでに `index.html` があるサイトでは上書きになるため、既存サイトを残したい場合は上記のサブフォルダ方式を使ってください。

一般的な静的ファイルを配信できるサーバー向けです。HTML、JavaScript、CSS、SVG、WOFF2の配信が必要です。独自のサーバー処理やURL書き換え設定は不要です。HTTPSが利用できる場合はHTTPSのURLを使ってください。

## 3. 公開後の確認

1. トップ画面で森とくまが表示されることを確認します。
2. 「あそぶ」→「はじめる」→「もじを さがす」でゲームを始めます。
3. 「もういちど きく」で音が出ること、文字を押すと反応することを確認します。
4. 5問遊び、ごほうびの花が増えることを確認します。
5. ページを開き直し、であった文字や花の記録が残っていることを確認します。
6. 使用予定のiPhone/iPad・Androidでも音声と操作を確認してください。

端末の日本語音声が使えないときは、お手本を見て同じ文字を選ぶ遊びに切り替わります。3Dが使えないときは静止した森を表示します。

## 4. 音が出ない場合

- 画面右上の音のボタンが「おとを けす」の状態、つまり音声オンになっているか確認します。
- 端末のメディア音量や消音設定を確認します。
- 「おうちのひとへ」→「音声を確認する」を押します。
- 端末の読み上げ設定に、日本語の音声が用意されているか確認します。日本語の音声データのダウンロードが必要な場合があります。
- 設定を変えたあとは、ゲームを再読み込みしてもう一度「はじめる」を押します。

ページを開いただけでは自動で読み上げません。操作したあとに音声を開始します。
声・読み方・利用可否は端末やブラウザによって異なります。利用する音声によっては通信が必要です。
「を」は「くっつきの を」として紹介し、お手本を必ず表示します。「お」と「を」を同時に選択肢へ出すことはありません。

## 5. 記録と設定

であった文字、集めた花、音声と動きの設定は、同じ端末の同じブラウザに保存されます。
会員登録や端末間同期はありません。同じドメイン内の別フォルダにゲームを置いた場合、記録は共有されます。

ブラウザのサイトデータを削除した場合や、ドメイン・HTTP/HTTPSを変えた場合、元の記録は引き継がれません。
プライベートブラウズなど、記録を保存できない環境でも、開いている間は遊べます。

「おうちのひとへ」で、音声・読む速さ・動きの量を変更できます。
「遊んだ記録をリセット」では確認画面が出ます。文字と花の記録だけが消え、音声と動きの設定は残ります。

文字の印は「遊んだ記録」です。習得したかどうかを判定するものではありません。

## 6. ゲームを更新する

新しい公開用フォルダができたら、同じ公開場所を更新します。

1. 新しい `assets` の中身を先にアップロードします。
2. `favicon.svg`、`licenses` を更新します。
3. 最後に `index.html` を更新します。
4. ページを再読み込みして新しい画面を確認します。

更新中に開いている人のため、古い `assets` のファイルは更新直後には削除しないでください。
表示が変わらない場合はブラウザの強制再読み込みや、レンタルサーバー側のキャッシュ削除を試してください。記録を残したい場合は、ブラウザのサイトデータ全体を消さないでください。

## 7. この版の範囲

ひらがな「あ〜ん」の46文字、お手本、3択5問、花のごほうび、もじずかんに対応しています。
濁音・半濁音・拗音、書き順練習、かたかな、アルファベットはまだ含まれません。

ブラウザ上の画面・操作は自動検証していますが、実機のiOS Safari / Android Chromeの音声品質・音量・発音は未確認です。公開前に使用予定の端末で確認してください。検証の詳細は開発資料の `検証結果.md` に記載しています。

## 素材について

3Dの森・どうぶつ・花は、このゲーム用にコードで作成した形状です。
文字フォントはFontworksのKlee One SemiBoldです。必要な文字を含むWOFF2に加工して同梱しています。
Three.jsのMITライセンスと、Klee OneのSIL Open Font License 1.1を `licenses` に同梱しています。

- Klee One：https://github.com/fontworks-fonts/Klee
